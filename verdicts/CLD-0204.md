# CLD-0204: Internal port sweep outside scan window: 203.0.113.44

Engagement: Cloudora · Shift 1 · 2026-08-25
Verdict: False positive · Severity (my rating): Informational (reported Medium)
QA review: Excellent

## Alert
Rule “TCP port sweep” fired from the Perimeter Firewall / IDS.

Source: 203.0.113.44 — LDN-SCAN-01

Time: Activity occurred from approximately 23:30 UTC Sunday night through 01:1x UTC Monday.

What triggered it: The host probed 3,800+ TCP ports across 160 internal hosts using sequential SYN probes, with no data transfer observed.

## Hypothesis
Malicious: An internal host may be performing network reconnaissance by scanning thousands of TCP ports across Cloudora's internal systems to identify available services and potential targets for further compromise.

Benign: LDN-SCAN-01 (203.0.113.44) is Cloudora's authorized vulnerability scanner performing its scheduled security scan. Although the activity occurred outside its normal weekly schedule, CHG-2101 specifically moved this week's scan to Sunday 23:00–Monday 03:00 UTC, which matches the observed activity.

## Evidence checked
Alert details: Reviewed the reported network activity from LDN-SCAN-01 (203.0.113.44). The host performed 3,800+ TCP port probes across 160 internal hosts between approximately 23:30 and 01:1x UTC.

Traffic pattern: Activity consisted of sequential SYN probes with no data transfer, which is consistent with port-scanning activity rather than an established data-transfer session.

Morning Handover / CHG-2101: Confirmed LDN-SCAN-01 (203.0.113.44) is the documented weekly vulnerability scanner. Although its normal schedule is Monday 22:00–Tuesday 03:00 UTC, CHG-2101 moved this week's approved scan to Sunday 23:00–Monday 03:00 UTC.

Timeline correlation: The observed activity from 23:30–01:1x UTC occurred entirely within the temporary CHG-2101 approved change window.

Source correlation: The source IP and hostname in the alert, 203.0.113.44 / LDN-SCAN-01, exactly match the scanner documented in the handover.

## Action
Closed as False Positive / authorized activity.

No escalation required.

No additional data required because the source, timing, and activity all match the documented CHG-2101 vulnerability scan window.

Monitoring: Continue normal monitoring. No special monitoring is necessary unless LDN-SCAN-01 begins scanning outside an approved window, its behavior changes significantly, or activity is observed from an unexpected source.

## Justification
Source: The activity originated from 203.0.113.44 / LDN-SCAN-01, which is identified in the Morning Handover as Cloudora's authorized vulnerability scanner.

Activity: LDN-SCAN-01 performed 3,800+ TCP port probes across 160 internal hosts using sequential SYN probes with no data transfer.

Schedule: The scanner normally operates Monday 22:00–Tuesday 03:00 UTC, but CHG-2101 moved this week's scan to Sunday 23:00–Monday 03:00 UTC.

Timeline: The observed activity occurred from approximately 23:30–01:1x UTC, entirely within the approved CHG-2101 window.

Verdict: False Positive, the detection correctly identified port-scanning behavior, but the activity was authorized vulnerability scanning.

Severity: Informational, no unauthorized or malicious activity was identified.

Disposition: Closed with no escalation required. Continue normal monitoring for scanning outside approved windows or unexpected changes in scanner behavior.

## Tuning note
Recommend change-window-aware tuning. Suppress or automatically lower the severity of TCP port-sweep alerts when the source is the documented LDN-SCAN-01 / 203.0.113.44 scanner and the activity occurs within an approved vulnerability-scanning/change window.

Continue alerting normally if the same source scans outside an approved window or if similar scanning originates from another host.

Risk: Overly broad suppression could hide unauthorized scanning or misuse of the scanner, so the exception should require both the approved scanner identity and an active approved change window.
